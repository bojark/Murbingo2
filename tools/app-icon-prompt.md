Prompt:

> Create one Windows desktop app icon using the provided raptor head as the precise identity reference. Keep its recognizable left-facing smiling open-jaw silhouette, grey-brown flat vector colors, orange-red eye, cream teeth and pink tongue. Clean compact square composition on a genuinely transparent background. Make the head occupy almost the full square with a small safe margin; simplify only tiny details so it reads at 32 pixels. No text, no lettering, no numbers, no bingo balls, no extra objects, no scenery, no border or badge. Preserve the friendly character and visual identity closely. Output a single icon, not an icon sheet.
